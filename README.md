# Présentation de l'application web de gestion de budget

Cette application web est une plateforme innovante qui permet à ses utilisateurs de gérer leur budget de manière interactive et intuitive. Développée avec les technologies PHP, JavaScript, HTML et CSS, elle propose une interface moderne inspirée des messageries iPhone pour une expérience utilisateur fluide et agréable.

## Fonctionnalités principales :

### Gestion interactive du budget :
L'application repose sur une approche unique : au lieu de naviguer dans des menus complexes, l'utilisateur interagit avec la base de données via un système de questions-réponses.

Exemple : "Mes achats étaient-ils nécessaires ?" ou "Quelle est ma dépense totale ce mois-ci ?"
Les réponses sont affichées instantanément sous forme de messages dans une interface de discussion intuitive.
Backend robuste :

### PHP traite les requêtes, interagit avec la base de données, et fournit des réponses rapides et précises basées sur vos données financières.
Un système sécurisé assure la confidentialité et la fiabilité de vos informations personnelles et financières.
Frontend inspiré des messageries iPhone :

### Bulle de discussion : Les questions posées et les réponses générées s'affichent sous forme de bulles modernes, organisées comme une conversation.
Interface épurée : Le design minimaliste met l'accent sur la clarté et l'accessibilité, pour une prise en main intuitive.
Animations fluides : Les transitions entre les actions sont douces, rendant l'expérience plus immersive.
